## 做了什么

公司财务每月用当月 1 号的汇率折算。原来是钉钉 AI 表格里的一条自动化流程(定时触发 → 查「十大银行外汇牌价」→ 循环新增记录 → 发钉钉消息),跑在钉钉里。这个案例把它的数据链路搬成**本机定时任务 + 飞书多维表**:

```
launchd(每月1号12:00) → 抓中行官网牌价页 → 24 币种校验 → 查当月是否已有批次
   → 建待办 → bot 身份批量写入飞书表 → 回读逐字段核对 → 通过则待办自动结单,失败则待办保持打开(+本机系统通知)
```

## 怎么跑

```bash
./setup_feishu_bot.sh                       # 一次性：配「RPA 通知机器人」配置档（用户输入凭据）
cp config.example.json config.local.json   # 填飞书 base_token / table_id / lark-cli 路径 / profile
python3 boc_fx_monthly.py --dry-run --force # 干跑:取数+校验+连飞书,不写
python3 boc_fx_monthly.py --probe-write     # 验写权限(写1行测试并删除)
./install_launchd.sh                        # 装定时任务(--pilot 先试跑,--uninstall 卸载)
```

## 随时获取当前汇率

如果只想查看当前中行牌价，不写入飞书，可以直接运行独立脚本：

```bash
python3 fetch_boc_rates.py                         # 终端表格，默认 24 种项目币种
python3 fetch_boc_rates.py --format json           # 输出 JSON
python3 fetch_boc_rates.py --format csv --output boc-rates.csv
python3 fetch_boc_rates.py --all --format json     # 输出官网当前解析到的全部币种
```

结果只返回代码、币种、汇率、含义和官网发布时间，例如 `AUD | 澳大利亚元 | 4.6959 | 1 AUD = 4.6959 CNY | 2026-10-07 09:51:46`。该脚本只访问中国银行官网，不需要飞书配置。

## 结论一览(每条标适用范围)

1. **原流程只查 BOC 一家**,银行编号写死 `BOC`;"十大银行"是组件名,不是这条流程的范围。【站点特有】
2. **表里每批稳定约 24 种外币,而 API 当次返回约 47 种**——存在一道固定的币种范围限制,不是偶发丢数据。公司只用这 24 种。【站点特有】
3. **中行折算价(midprice)一天内不变;买入卖出价全天多次浮动**(10-01 当天 159 条报价,折算价始终一个值,买卖价 3 种取值)。财务只用折算价时,可用同日或相邻假日的折算价核对。【领域通用:银行牌价类】
4. **国庆假期折算价冻结**(10-01 与 10-05/06 的 24 个币种折算价完全一致),但买卖价不冻结。【领域通用】
5. **飞书用户令牌刷新期约 7 天,不能用于月度无人值守任务**,必须用应用(bot)身份。【完全通用:飞书 OAuth 类】
6. **bot "能读不能写"是常见假象**:读靠组织级可读,写需要应用是协作者。读通了不代表写得通。【完全通用:飞书多维表类】
7. **中行历史牌价检索有滑块验证码,不可程序化**;只能人过验证码、agent 读结果。【站点特有】
8. **`lark-cli` 到飞书的 EOF 偶发很频繁**(本次探路中至少 5 次,涉及读、写、取令牌各环节),写入类调用不能盲目重试,要先查"其实已写入"。【完全通用】
